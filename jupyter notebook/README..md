ANALYSES DES NOTES D'ANIMES

Description du projet :

 Ce projet consiste en une analyse de données portant sur un ensemble d’animés. L’objectif principal était d’analyser les notes globales, de calculer un score basé sur plusieurs critères, de visualiser les données à l’aide de graphiques et d’interpréter les résultats obtenus. Le travail a été réalisé dans un Jupyter Notebook dans le cadre d’un devoir académique.
Contenu du projet :
Le notebook principal contient le code, les graphiques et les analyses.
Un fichier README décrit le projet.
Eventuellement, un dossier contenant les données si nécessaire.
Technologies utilisées :
Le projet a été réalisé en Python 3, en utilisant Jupyter Notebook. Pour la manipulation des données, j’ai utilisé Pandas, pour la visualisation Matplotlib, et pour certaines analyses de classification et métriques, Scikit-learn.

Méthodologie :
J’ai commencé par créer et préparer le jeu de données. Ensuite, j’ai calculé différents indicateurs, comme l’écart entre le meilleur et le pire épisode, la régularité des animés et un score pondéré que j’ai appelé score métier. Après cela, j’ai effectué une analyse descriptive pour classer les animés et visualiser les résultats avec des graphiques. Enfin, j’ai interprété ces résultats pour tirer des conclusions claires sur la qualité et la régularité des animés.

Résultats principaux :
Le projet m’a permis d’identifier les animés les mieux classés selon le score métier, de visualiser la répartition des animés selon leur statut (terminé ou en cours) et de présenter les résultats de manière claire pour faciliter l’interprétation.
